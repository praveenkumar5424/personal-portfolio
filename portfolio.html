04 · Case Study

Tamil Nadu Agricultural Hub

An AI-powered decision-support system built for farmers — from crop advice to disease diagnosis.

React 19TypeScriptNode.jsExpress Google Gemini APIREST APITailwind CSS

Helping farmers make faster, better-informed decisions with AI.

A full-stack web application delivering AI-driven crop recommendations, soil analysis, and market/weather insights — with a multilingual assistant that speaks the farmer's language.

Problem

Farmers lack fast, localized guidance

Smallholder farmers often make critical crop and treatment decisions without easy access to expert advice, especially in regional languages, and without an easy way to interpret soil conditions or spot crop disease early.

Role

Full-stack builder, solo project

  • Architected the React 19 + TypeScript frontend and Express backend
  • Integrated the Gemini API for structured AI outputs
  • Designed REST endpoints and the conversational assistant flow
Solution

An AI advisor farmers can talk to

  • JSON-schema-driven crop recommendations from Gemini
  • Image-based crop disease diagnosis from soil/photo inputs
  • Multilingual chat assistant in Tamil, Hindi & English
Outcome · What it delivers
Structured AI advice
